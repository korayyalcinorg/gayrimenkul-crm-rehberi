# Gayrimenkul CRM Kurulum Kontrol Listesi

Bu kontrol listesi, yeni CRM kurulumu veya mevcut CRM'in yeniden yapılandırılması sırasında kullanılabilir.

## A. İş süreci

- [ ] Lead kaynakları listelendi
- [ ] Satış aşamaları tanımlandı
- [ ] Qualification kriterleri belirlendi
- [ ] No Response süreci tanımlandı
- [ ] Randevu süreci tanımlandı
- [ ] Follow-up kuralları yazıldı
- [ ] Kayıp nedenleri standardize edildi

## B. Veri alanları

- [ ] Telefon
- [ ] E-posta
- [ ] Ülke
- [ ] Dil
- [ ] Lead source
- [ ] Campaign
- [ ] Project
- [ ] Budget
- [ ] Down payment
- [ ] Purchase timeline
- [ ] Assigned representative
- [ ] First contact time
- [ ] Last contact time
- [ ] Lost reason

## C. Entegrasyonlar

- [ ] Meta Lead Ads
- [ ] Web sitesi formları
- [ ] Google Ads / UTM
- [ ] WhatsApp
- [ ] SMS
- [ ] E-posta
- [ ] Takvim
- [ ] Telefon sistemi

## D. Otomasyon

- [ ] Otomatik lead atama
- [ ] Yeni lead bildirimi
- [ ] İlk temas görevi
- [ ] SLA uyarısı
- [ ] NR takip görevleri
- [ ] Randevu hatırlatma
- [ ] Follow-up görevi
- [ ] Kayıp nedeni kontrolü

## E. Veri kalitesi

- [ ] Duplicate kontrolü
- [ ] Telefon normalizasyonu
- [ ] Zorunlu alanlar
- [ ] Eski / geçersiz kayıt politikası
- [ ] Yetkilendirme rolleri

## F. Raporlama

- [ ] Lead dashboard
- [ ] Contact Rate
- [ ] Speed-to-lead
- [ ] Appointment Rate
- [ ] Show-up Rate
- [ ] Sales Conversion
- [ ] Cost per Sale
- [ ] Lost reasons
- [ ] Temsilci performansı

## G. Kullanıcı eğitimi

- [ ] Aşamaların anlamı anlatıldı
- [ ] Not girme standardı belirlendi
- [ ] Görev kapatma standardı belirlendi
- [ ] Randevu sonucu nasıl girilir anlatıldı
- [ ] Lost nedeni seçimi anlatıldı
- [ ] Mobil kullanım test edildi

## H. İlk 30 gün kontrolü

CRM yayına alındıktan sonra ilk ay içinde şunlar gözden geçirilmelidir:

- Kullanılmayan alanlar
- Yanlış atama kuralları
- SLA ihlalleri
- Eksik kaynak bilgileri
- Çok fazla / çok az pipeline aşaması
- Temsilci geri bildirimleri
- Raporlarda veri boşlukları

CRM kurulumu tek seferlik proje değil, düzenli optimizasyon sürecidir.
