# Katkı Rehberi

Bu repo, gayrimenkul CRM ve lead yönetimi konusunda pratik Türkçe kaynak üretmeyi amaçlar.

## Katkı türleri

Aşağıdaki katkılar değerlidir:

- Yeni CRM kullanım senaryoları
- Lead routing örnekleri
- Lead scoring yaklaşımları
- CRM KPI önerileri
- WhatsApp / SMS / e-posta otomasyon akışları
- CRM entegrasyon örnekleri
- Hatalı veya güncelliğini yitirmiş bölümlerin düzeltilmesi
- Yeni terimlerin sözlüğe eklenmesi

## İçerik prensipleri

- Reklam veya gizli satış metni eklemeyin.
- Gerçek müşteri kişisel verisi paylaşmayın.
- Örnek veriler sentetik olmalıdır.
- İstatistik veya benchmark iddiası varsa kaynak belirtin.
- Belirli bir CRM ürününü gereksiz yere üstün göstermeyin.
- Hukuki konuları kesin danışmanlık diliyle yazmayın.

## Pull request yapısı

Katkı gönderirken:

1. Değişikliğin amacını kısa açıklayın.
2. Yeni dosya ekliyorsanız README dizinine eklenmesi gerekip gerekmediğini belirtin.
3. Örnek veri kullanıyorsanız kişisel veri içermediğini kontrol edin.
4. Mümkünse değişikliğin uygulanabilir kullanım senaryosunu ekleyin.
